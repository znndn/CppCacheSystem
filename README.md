# 基于 C++ 的缓存系统

- 使用 C++20 实现 LRU（最近最少使用）、LFU（最不经常使用）及带频率老化的 LFU。三种策略共用一套缓存接口，测试程序使用相同的热点访问序列对比命中率。
  
- 针对LFU算法引入平均访问频次阈值及批量降频机制，缓解陈旧热点数据长期占用缓存的问题；通过互斥锁保护 get/put 操作。
  
- 模拟实际环境中约 70% 读、30% 写的混合负载，执行 50 万次操作，对比 LRU、LFU 无衰减及有衰减配置的命中率、耗时对比及异常捕捉，并校验命中结果。

## 构建与运行

需要 CMake 3.16 或更高版本，以及支持 C++20 的编译器。

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/CacheAlgorithm
```
